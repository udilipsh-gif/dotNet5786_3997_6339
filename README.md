# 📦 מערכת לניהול שליחויות (Delivery Management System)

ברוכים הבאים למערכת ניהול השליחויות – פתרון תוכנה מקיף שנכתב ב-**.NET (C#) ו-WPF**.
המערכת מספקת פתרון מלא לניהול חברת שליחויות, החל משלב הזמנת המשלוח, דרך ניהול צי השליחים, ועד למעקב בזמן אמת וסימולציית זמן.

---

## ✨ תכונות מרכזיות (Features)

### 👥 עבור מנהלי מערכת (Manager)
* **ניהול שליחים:** הוספה, עדכון ומחיקה של שליחים. צפייה בסטטיסטיקות ביצועים (איחורים/בזמן).
* **ניהול הזמנות:** צפייה בכל ההזמנות במערכת, סינון לפי סטטוסים ומעקב אחר התקדמות.
* **שליטה בזמן (סימולטור):** הרצת שעון וירטואלי המאיץ את הזמן ומבצע פעולות אוטומטיות ברקע.
* **ניהול קונפיגורציה:** הגדרת כתובת החנות, טווחי משלוח, מהירויות כלי רכב ועוד.

### 🛵 עבור שליחים (Courier)
* **אזור אישי:** כניסה מאובטחת למערכת.
* **בחירת משלוחים:** צפייה ברשימת "הזמנות פתוחות" הרלוונטיות לכלי הרכב ולמרחק של השליח.
* **ניהול משלוח פעיל:** איסוף משלוח, צפייה בפרטי היעד, ודיווח על סיום (נמסר/נכשל).
* **מפות וניווט:** צפייה במפה סטטית (Google Maps) ומידע על מסלול (מרחק וזמן משוער).

### ⚙️ מנוע הסימולציה והלוגיקה העסקית
* **עדכונים בזמן אמת (Observer Pattern):** הממשק מתעדכן אוטומטית ללא צורך ברענון ידני בעת שינויי סטטוס.
* **חישובי מרחק וזמן:** שימוש בנוסחת Haversine ו-Google Maps API לחישוב מרחקים וזמני הגעה מדויקים.
* **ניהול סיכונים:** זיהוי אוטומטי של הזמנות בסיכון (InRisk) או באיחור (Late).
* **תקשורת:** שליחת התראות דוא"ל (via Google Script) ו-SMS (via Call2All) לשליחים בעת הקצאת משלוח או ביטול.

## 🏗️ ארכיטקטורה וטכנולוגיות

הפרויקט בנוי בגישת **3-Tier Architecture**:

1.  **PL (Presentation Layer):**
    * נכתב ב-**WPF** עם XAML.
    * שימוש ב-**Data Binding**, **Value Converters**, ו-**Dependency Properties**.
    * ממשק מודרני עם חלונות פופ-אפ (כגון `MapPopupWindow`).
2.  **BL (Business Logic Layer):**
    * מכיל את כל הלוגיקה העסקית (`OrderManager`, `CourierManager`, `DeliveryManager`).
    * ניהול **Cache** פנימי לשיפור ביצועים.
    * שימוש ב-**Thread Safety** (מנעולים ו-Mutex) למניעת התנגשויות בגישה לנתונים.
3.  **DAL (Data Access Layer):**
    * גישה לנתונים (XML / List) דרך ממשק אחיד (`IDal`).

### 🛠️ טכנולוגיות וכלים
* **Language:** C# .NET 8
* **UI:** Windows Presentation Foundation (WPF)
* **Concurrency:** `Task`, `async/await`, `Mutex`, `IAsyncEnumerable`.
* **External APIs:** Google Maps Platform (Geocoding, Distance Matrix, Static Maps).
* **Design Patterns:** Singleton, Factory, Observer, Facade.

## 🧩 מבנה הקוד (Highlights)

* **`Helpers.Tools`**: מחלקת שירות סטטית המכילה פונקציות לחישובי מרחק, ולידציות, המרות סטטוסים ותקשורת חיצונית.
* **`AdminManager`**: הלב של הסימולטור. מנהל את ה-`Clock`, מריץ `PeriodicSystemUpdates` ודואג לסנכרון בין כל התהליכונים.
* **`ObserverMutex`**: מנגנון ייחודי שפותח בפרויקט כדי למנוע Race Conditions בין עדכוני UI (מהירות תצוגה) לבין חישובים כבדים ברקע.
* **`MapPopupWindow`**: חלון WPF המציג תמונה סטטית של המסלול באמצעות קישור דינמי ל-Google Static Maps API.
